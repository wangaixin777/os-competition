# Lab3 编译启动命令清单

## 适用环境
希冀平台 Web 虚拟机（Ubuntu 24.04）、本地预装 RISC-V 交叉编译工具链的 Ubuntu 环境，适用于 `main-baseline` 原生 RR 调度基线版本。

---

## 1. 获取源码并切换基线分支
```bash
# 克隆远程仓库
git clone [https://github.com/wangaixin777/os-competition.git](https://github.com/wangaixin777/os-competition.git) lab3

# 进入项目目录
cd lab3

# 切换到纯净基线分支
git checkout main-baseline
```

## 2. 编译内核
```bash
make build
```
**说明**：调用 riscv64 交叉编译工具链编译内核源码，生成内核可执行文件。终端无报错输出即编译完成。

## 3. 生成文件系统镜像
```bash
make fs
```
**说明**：
- 执行过程中会请求 sudo 权限，希冀平台虚拟机默认 `ubuntu` 用户的密码为 `ubuntu`
- 命令执行完成后生成 `fs.img` 文件系统镜像，内置所有用户态测试程序

## 4. QEMU 启动内核
```bash
make run
```
**说明**：启动 QEMU 虚拟机并加载内核与文件系统。正常启动后将出现 xv6 shell 提示符 `-> / $`，可执行 `ls` 等基础命令验证系统可用性。

## 5. 退出 QEMU
在 QEMU 运行窗口中，按以下两步操作退出：
1.  按住 `Ctrl + A`，全部松开
2.  按下 `X`

即可退出虚拟机，返回终端命令行。

## 6. 可选：清理编译产物
```bash
make clean
```
**说明**：清除所有编译生成的目标文件、内核镜像与文件系统镜像，用于完整重新编译。
