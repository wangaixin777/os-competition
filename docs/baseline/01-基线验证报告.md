# Lab3 原生RR调度基线验证报告

## 1. 验证目的
确认 Lab3 原版源码可正常编译、QEMU 启动运行，RR 调度行为符合预期，作为后续 MFQ 开发的基准基线。

## 2. 环境信息
- 运行环境：希冀平台 Web 虚拟机（Ubuntu 24.04）

  交叉编译器：riscv64-unknown-elf-gcc （13.2.0-11ubuntu1+12） 13.2.0

- QEMU 版本：QEMU emulator version 8.2.2 (Debian 1:8.2.2+ds-0ubuntul.17)

- 基线分支：main-baseline

- 源码提交号：a40a2c0ca08f3ab7cb289caa50e9b92blc157df0

## 3. 验证步骤
1. 克隆仓库，切换到 main-baseline 分支
2. 执行 `make build` 编译内核
3. 执行 `make fs` 生成文件系统镜像
4. 执行 `make run` 启动 QEMU
5. 进入 shell 后执行 `ls` 基础命令，验证系统交互正常
6. 正常退出 QEMU（按 `Ctrl+A`，松开后按 `X`)

## 4. 验证结果
- 编译：无错误、无警告阻断，内核镜像生成成功
- 启动：OpenSBI 引导正常，内核无 panic，成功进入 `-> / $` shell
- 交互：基础命令执行正常，进程调度无异常
- 结论：✅ 原生 RR 调度基线验证通过
